# planificador_turnos-client

## Requisitos
- Node.js 20+
- Angular CLI 19

## Instalación
```bash
npm install
```

## Desarrollo
```bash
ng serve
```
Abre `http://localhost:4200/` en tu navegador.

## Build
```bash
ng build
```

## Docker
```bash
docker build -t <IMAGE_NAME> .
docker push <IMAGE_NAME>
```
